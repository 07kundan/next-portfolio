# Personal Porfolio

## Deployment

The porfolio is automatically deployed to Vercel whenever changes are pushed to the `main` branch. You can access the live website at `https://auric-one.vercel.app/`.

## Technologies Used:

- Nextjs: A powerful JavaScript Framework.
- Framer Motion: Enables creation of smooth, performant animations for an enhanced user experience.
- Sanity: For creation and managing content.

**Features:**

- **Drag Button**: Navigate through routes by dragging.
- **AI Genearted Feedback**: You can generate Feedback using AI by providing prompt or just some keyword.
- **Themes**: You can toggle between dark and light theme.
- **SSR and Memoized Component**: Pages are SSR and Memoized.
- **Responsive Design**: Porfoilo is fully responsive.
